# III Encuentro Empresarial · ANI · UNIPAZ

Espacio de trabajo de los estudiantes de Consultorio Empresarial para el III Encuentro Empresarial:
video de instrucciones, documentos, responsabilidades con barra de cumplimiento, muro de mensajes
y panel de seguimiento para el docente y la coordinación.

- `index.html`: la aplicación.
- `config.js`: aquí se pega la URL de Apps Script. Si está vacía, la app funciona en modo demostración.
- `motor-demo.js`: motor del modo demostración.

Los datos (usuarios, tareas, avances, mensajes, documentos) viven en una hoja de Google conectada con Apps Script.
